# ADR 0001: Apache License 2.0

## Status

Accepted (2026-10)

## Context

NeuroCut needs an OSI license that allows commercial use and modification, requires attribution, and does not force derivative products to be open source (no strong copyleft).

## Decision

Use **Apache License 2.0**.

## Consequences

- Compatible with SaaS / commercial NLE plugins built on NeuroCut
- Explicit patent grant (helpful for AI tooling ecosystems)
- Requires NOTICE / attribution retention
- Not viral like GPL — contributors must accept that forks can be closed-source
