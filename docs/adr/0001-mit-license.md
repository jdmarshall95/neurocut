# ADR 0001: MIT License

## Status

Accepted (2026-10) — supersedes Apache-2.0 for the public release packaging.

## Context

NeuroCut needs a simple OSI license that allows commercial use and modification
with attribution, without strong copyleft.

## Decision

Use the **MIT License**.

## Consequences

- Easy for commercial NLE plugins and SaaS forks
- Minimal compliance overhead (copyright + license notice)
- No explicit patent grant (unlike Apache-2.0) — acceptable for this project scope
